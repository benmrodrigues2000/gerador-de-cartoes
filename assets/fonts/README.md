# Bundled typefaces

Latin and Latin Extended WOFF2 subsets, distributed through Fontsource. All are licensed under the SIL Open Font License 1.1; original license and copyright notices are in `licenses/`. Variable fonts include the available normal-weight range. Static families include the weights used by Card Studio.
